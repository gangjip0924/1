**One-sentence pitch:** 꺼져가는 등불 하나와 d20 주사위만 들고, 혼자서 의뢰를 하나씩 해결해 나가는 솔로 판타지 TRPG.

## Core loop
- 마을 게시판에서 의뢰를 고른다.
- 장면 카드를 읽고 행동을 고른다 (힘 / 재치 / 마음 중 하나로 판정).
- d20 + 능력치로 판정하고, 결과에 따라 이야기가 갈린다. 실패해도 이야기는 계속되지만 등불 기름이 줄어든다.
- 다음 장면으로 넘어가 기름이 남아 있는 동안 의뢰의 끝까지 간다.

## Player goal & fail state — what "working" looks like
- 목표: 등불이 꺼지기 전에 의뢰의 마지막 장면에 도달해 의뢰를 완수한다.
- 실패: 체력이 0이 되거나 등불 기름이 바닥나면 의뢰 실패. 한 판은 10~20분 안에 끝난다.

## MVP — what must exist to be the game
- 캐릭터 1명: 능력치 3개(힘 / 재치 / 마음)와 체력
- d20 판정 시스템: 난이도 대비 성공 / 부분 성공 / 실패 3단계
- 등불 기름 시계: 장면마다, 실패할 때마다 줄어드는 남은 시간
- 장면 카드: 서술 텍스트와 선택지 2~3개, 데이터 파일로 작성
- 의뢰 1개: 장면 6~8개, 분기 포함
- 결과 화면: 성공 / 실패와 받은 보상 표시

## Out of scope — not building this
- 멀티플레이, 여러 캐릭터로 된 파티
- 저장 / 불러오기 (한 판이 짧아서 필요 없음)
- 격자 전투, 레벨업, 장비 시스템
- 음성 녹음, 애니메이션 컷신

## Build order
1. 텍스트만으로 판정과 기름 시계 프로토타입: 주사위와 시계만으로 긴장감이 생기는지 먼저 확인
2. 장면 데이터 형식과 의뢰 1개 작성
3. 주사위 굴림 연출과 화면 구성
4. 결과 화면
5. 일러스트와 사운드

---
**Who it's for / what they feel:** TRPG를 해보고 싶지만 같이 할 사람이 없는 사람이, 주사위를 굴릴 때마다 손에 땀을 쥐는 느낌.

**Art & audio direction:** 양피지 질감의 손그림 일러스트, 촛불 빛 같은 따뜻한 색감, 조용한 류트 배경음.

**Reference game:** 솔로 게임북(선택지 번호를 따라가는 책) — 장면 단위로 고르고 판정하는 흐름만 가져오고, 전투 규칙과 장비 관리는 뺀다.
