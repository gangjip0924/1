# ADR-0004: 검증 보고서와 "왜 이 이벤트가 안 떴나" 디버그 뷰

- 상태: 채택 (2026-10-30)

## 결정

- **검증 보고서**: 팩마다 `로드됨/거부됨`, 항목 수, 오류(경로 포함), 경고(예: 해금 경로가 없는 장면). 오류가 하나라도 있으면 팩 전체를 로드하지 않는다(부분 로드 없음).
  - 게임 화면: 타이틀 → 모드팩. 명령줄: `npm run validate`.
  - 다수 팩의 ID 충돌은 MVP 범위 밖이므로, 이미 쓰인 ID를 다시 정의한 팩은 거부한다. 로드 순서는 `core` 먼저, 나머지는 이름순.
- **디버그 뷰**: 설정에서 켠 뒤 게임 중 F9(또는 일시정지 메뉴). 모든 사건에 대해 가능/불가, 가중치, 우선순위, 연쇄 대기, 겪은 횟수,
  그리고 불가 이유(`나이 범위 밖`, `이미 겪은 일회성 사건`, `조건 불충족: …`)를 사람이 읽는 문장으로 보여 준다(`explainCondition`).
- **시뮬레이터**: `node tools/simulate.js 1000 random` — 사건 도달률, 장면 해금률, 진로별 금화 분포. 5% 미만으로 등장하는 사건을 따로 보고한다.
