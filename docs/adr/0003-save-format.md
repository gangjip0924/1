# ADR-0003: 세이브 형식과 버전 관리

- 상태: 채택 (2026-10-30)

## 결정

- 세이브(`userdata/store/autosave.json`)는 `{saveVersion, savedAt, packs:[{id,version}], signature, state}`.
- `state`에는 **콘텐츠 ID만** 담는다(사건·특성·장면 정의 자체를 복사하지 않는다). RNG 상태도 저장해 이어하기가 결정적이다.
- 불러올 때(`src/shared/save.js` `loadSave`):
  - 종족·신분·출생지가 사라졌으면 **거부**(이어 갈 수 없음).
  - 특성·장면·업적·연쇄 대기 사건·진로가 사라졌으면 **떨구고 경고**를 보여 준다.
  - 팩이 빠졌거나 버전이 바뀌었으면 경고한다.
  - 더 새로운 `saveVersion`은 거부한다.
- 영구 기록(meta: 업적, 갤러리, 최고 기록, 최근 생)은 세이브와 분리해 `meta.json`에 둔다. 사라진 업적은 이월 포인트 계산에서 빠진다.
- 자동 저장: 사건이 제시될 때와 선택을 확정한 직후. 생이 끝나면 자동 저장을 지운다(로그라이트).

## 후속

`saveVersion`을 올릴 때는 `loadSave`에 이전 버전 변환 단계를 추가한다.
