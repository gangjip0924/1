# ADR-0005: 장면 이미지 생성의 신뢰 경계

- 상태: 채택 (2026-10-30)
- 관련: 컨셉 문서 Image Generation Rules — "게임 코드가 강제, 프롬프트 안내로 대체 불가"

## 결정

1. **프롬프트는 서버가 조립한다.** 브라우저는 `{sceneId, char:{race, appearance, seed}}`만 보낸다. 서버는 자기가 로드·검증한 모드 데이터로
   `스타일 락 접두사 + 종족 + 인생 단계 + 외형 어휘 + (성년·노년만) 추가 묘사 + 등장인물 + 장면 태그`를 만든다(`src/shared/prompt.js`).
2. **외형은 어휘 목록 값만** 받는다(성별·머리·눈·피부). 자유 서술(`extra`, 200자)은 성년·노년 단계에서만 쓴다.
3. `checkGenerationRequest`(`src/shared/safety.js`)가 생성 직전에 다시 검사한다:
   - 금지 태그(NTR·"미시" 유형) → 거부
   - 실존 인물 표지 단어·차단 목록 → 거부
   - 등장인물: `fictional: true`이고 20세 이상 → 아니면 거부
   - 20세 미만 단계(child/teen): 일반 등급만, 성적·노출 표현 → 거부, 안전 부정 프롬프트 강제
   - 성인 등급: 설정에서 켰을 때만, 성년·노년 단계에서만
4. 모드 로드 단계에서도 같은 규칙을 검사한다(이중 방어). 로드 단계에서 걸러지면 팩 전체가 거부된다.
5. 생성기 주소는 루프백(127.0.0.1/localhost)만 허용한다 — "생성은 로컬에서만".
6. 캐시 키 = SHA-256(최종 요청 + 스타일 버전). 같은 장면은 다시 만들지 않는다. 생성 실패·미생성 장면은 기본 삽화로 대체하고 게임은 계속된다.

## 한계 (정직하게)

- 실존 인물 판별은 표지 단어와 사용자 차단 목록에 기대며 완전하지 않다. 이름 목록은 사용자가 `blocklist.json`에 추가해야 한다.
- 키워드 검사는 우회 표현을 모두 막지 못한다. 그래서 20세 미만 단계는 "금지어 거르기"가 아니라 "자유 서술을 아예 넣지 않기 + 안전 부정 프롬프트"를 기본으로 삼았다.
- 기준 이미지(IP-Adapter) 얼굴 고정은 실제 생성기로 시험하지 않았다(실험적 설정).
